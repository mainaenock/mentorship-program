## Implementation sequence

1. Typed portal contracts, scoped demo repository, route registry and granular permission policy. Preserve owner, assigned-mentee and linked-child boundaries; exclude private reflections and mentor notes from guardian projections. Financial state comes from the adapter, never a success query parameter.
2. Reusable authenticated desktop/mobile shell with role-specific five-item navigation, secondary drawer, collapsible sidebar, search, notifications, help, user menu, breadcrumbs and contextual actions.
3. Member dashboard and full eleven-step goal wizard. Weighted milestone progress; complete action recurrence and occurrence transitions; evidence, check-ins, immutable evaluations, recovery interventions, history and earned achievements.
4. Learning catalog/detail/player for all ten material types, bookmarks, purchase/credit eligibility, learning progress and certificates where configured. Auditable credit/payment state interfaces, receipts and refund requests.
5. Member mentorship, sessions and messages; mentor dashboard and assigned-mentee workspace, evaluations, notes, recommendations, interventions, availability, reports and compliance.
6. Guardian relationships, scoped child overviews, consent grants/withdrawals, sessions, safety reports, privacy and settings.
7. Administrator route registry and domain-specific operations, granular staff permissions, searchable/filterable/sortable/paginated records, saved views, selection, authorized exports, detail workflows and audit. Overview funnel and reports with textual chart summaries.
8. Profile, security, notifications, privacy, support and remaining shared account workflows. Every visible control gets a concrete outcome, loading/error state and backend contract.
9. Complete route and interaction inventories; update all shared docs and exact Prompt 3 handoff. Execute full acceptance checks.
